# 全路线许可：可执行收益与边界

本实验直接调用同构Agent核心，使用真实Flatland env.step、固定路线、原生故障关闭和同一外部STOP事件表。复用统一datasets/mpc-flatland-v1，不改变场景来挑赢家。三个已接触场景、三档扰动、四方法共36局，全部保留。

本轮要检验的狭义问题：共享路线的成员在其他成员完成前保持互斥许可，不相交路线可并行；可执行许可不变时，按需询问能否替代反复询问。许可仅修改SegmentedPlan的permit片段，other_work不变。不能声称已实现窗口换序、复杂连锁修复或完整MPC优化。

所有方法共享路线及扰动；periodic/periodic1/event共享许可决策和轮换发起，分别每8步询问、每步询问、只有等待且前驱清空时询问。serial是全车串行参照，不是同机制消融。状态变化向所有成员公开，按接收者记录消息和字节，全部计入total_bytes；假设同步可靠观测，不是通信延迟实验。

## 这能说明什么

这是一项真实执行的正面证据，支持“外部条件没变就保留许可、仅在需要时协调”的具体设计。它不证明六模块整体优越，不证明LLM增益，也不证明超过成熟事件触发调度。事件触发本身已有先例，不能把节省重复询问当作独有新颖性。

只有三个开发场景，不能据63辆次宣称统计显著；未增加新种子保留测试。最多同时在轨两车，整条路线互斥较保守，并不是用户期望的大规模高复杂连锁场景。若继续改进，应保持这项正面证据的范围，另测细粒度区段和连锁响应，不把本轮写成全部研究目标完成。
