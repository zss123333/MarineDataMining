# 通用Agent协调观察台

## UML式时序展示

sequence.js绘制SVG生命线、横向消息箭头、自调用回环和工具执行激活条，纵向按实际日志记录顺序排列，并非墙钟等比例图。主图只显示任务语义和协调解释，原JSON默认收起，点击图中事件检查。任务名称可通过taskNames扩展；未知任务保留原名称，不能自动理解任意业务语义。消息解释只使用真实payload，缺少工作名时明确提示缺失，不用别人的模型结果填充。执行状态只依赖模型决策与真实工具回执，不把commit当成工作完成。旧版无事件日志的结果不能恢复准确时序。语义测试运行node test_sequence.cjs。

## 三列时序视图更新

新任务使用Agent0、1、2三名成员，reference由Agent0执行；历史四成员对照仍保持原配置。界面每行展示一次真实发送、模型输出或工具事件，按事件顺序从上至下排列；消息正文payload直接显示，并画发送方到接收方的横向箭头。原始完整事件仍可展开。模型当前输出主要为结构化JSON，并没有自然语言自由聊天，不将协议模板冒充模型说的话。旧result只有汇总trace不能恢复消息正文，需要选择events.jsonl或开始新任务。

## 聊天式交互界面

新版提供基础依赖协作、执行中新增依赖两个任务选项，点击开始才由后端启动真实LLM实验。群聊气泡展示实际消息发送和工具状态，文字是协议类型的可读解释，不伪造自然语言聊天；原始消息可展开。成员卡片显示最近工具工作或协调状态。任务入口通过白名单限制，禁止并发开启多个界面任务，子进程控制台写入expr/live-ui对应批次console.log，事件在local-0/events.jsonl。

前端通用的是事件协议及展示，不是任意任务自动注册。当前两个选项对应统一工具任务的基础/动态两种配置，并非已接入铁路和烹饪；添加其他任务须注册受控入口并输出相同事件协议。工具完成后卡片保留最近工作结果，不推测成员脑内状态。

服务不会自行启动实验或自动打开浏览器。运行server.py后手动访问127.0.0.1:8765；点击开始将调用本机Ollama，依赖003隔离环境中现有AutoGen安装。服务只允许本机访问，任务开始接口拒绝跨源Origin。停止服务不会自动终止已经启动的实验子进程，勿误以为网页关闭即取消任务。

纯Python标准库服务和单页HTML，无需npm安装。只监听127.0.0.1，浏览器访问http://127.0.0.1:8765 。界面提供实验来源选择、序号回放、Agent最近事件、执行快照、按成员/类型/关键词筛选、完整原始数据展开和JSON导出；开启自动刷新后每3秒读取落盘日志。

已有result/results及trace/calls自动适配，不假定烹饪、铁路或工具名称。历史数据缺少执行者、对端或时间时显示未知；各块不能重建真实全局时间线，Agent卡片仅表示最近观测事件，不是假装实时执行状态。未知结构可保留summary原始数据，但不保证所有旧格式有专用可视化。

新任务推荐使用核心源码/telemetry.py的EventLog，写入expr任意实验目录的events.jsonl，每行事件包含kind、agent、peer、time、wall_time及业务数据。LoggedTransport包装既有消息传输，记录发送和接收；LoggedClock包装现有Clock，记录动作提交、调用返回和异常堆栈，返回不代表动作完成。真实完成需由执行层另外emit。动态实验dynamic.py已接入消息、工具回执、依赖变化、执行快照和异常日志，未来运行生成；旧实验不会被伪造补齐日志。

工具示例：log.emit('tool', agent='A', time=3, status='running', task_id='job-1')。协调消息保留发送者、接收者、提案与载荷；必要时以提案编号搜索，结合模型原文定位。日志可能含任务数据和模型上下文，仅在本机使用，分享前自行脱敏；不要记录密钥。server.log保存HTTP访问与服务异常。

查看器是只读观察工具，不负责启动实验或控制Agent。新任务需输出统一事件或添加历史适配器，不承诺无接入即可还原任意任务内部状态。三项测试覆盖路径越界、历史适配和消息日志。
