# TIE：摘要与核心内容中文译文

[返回笔记](2604.00499-TIE.md)。原作者Haoyu Zheng等，*Scheduling LLM Inference with Uncertainty-Aware Output Length Predictions*，https://arxiv.org/abs/2604.00499v2 ，CC BY4.0。AI辅助翻译日期2026-11-08。本文仅翻译摘要和所列核心段落，不是全文翻译；公式以行内形式重排。

## 一、摘要（PDF第1页，完整翻译）

在调度LLM推理时，最短作业优先（SJF）原则有利于优先处理输出较短的请求，以避免队头阻塞。现有方法通常为每个请求预测一个输出长度，以便进行调度。我们认为，这种单点估计与LLM推理的随机解码过程不匹配：输出长度天然不确定，取决于何时采样到序列结束（EOS）token。因此，每个请求的输出长度应拟合成分布，而不是单个值。通过对经验数据和随机解码过程的深入分析，我们观察到输出长度具有重尾分布，并可用log-t分布拟合。在此基础上，我们提出称为尾部膨胀期望（TIE）的简单指标，用来替代SJF调度中的输出长度。它利用尾部概率调整log-t分布的期望，以考虑请求生成长输出的风险。为评估TIE调度器，我们将其与三个强基线比较；结果显示，TIE使在线推理的每token延迟改善2.31倍，并使离线数据生成吞吐提高1.42倍。

## 二、问题与方案分解（第3页§3开头）

输出长度分布预测包含两个部分：（1）选择并拟合合适的分布来建模输出长度；（2）训练预测器，估计输出长度分布的参数。

LLM推理本质上具有随机性。每一步解码，下一token都从依赖前文的概率分布中采样。因此，相同输入提示可能产生不同输出。

为了研究相同提示下的输出长度分布，我们从LMSYS-Chat-1M采样1,000个提示，并为每个提示生成100个回答。我们观察到这些分布呈现明显重尾特征：在1,000个分布中，平均偏度为3.10，平均变异系数为1.09，其中78.6%的变异系数大于1。最长的10%输出贡献总长度的35.7%，平均P90/P50和P99/P50分别达到4.62和10.77。

## 三、分布选择（第3页§3.1选段）

表1总结不同分布的参数数目和拟合表现。三参数log-t分布取得最高通过率93.1%。由于log-t具有专门控制尾部行为的参数ν，我们进一步比较不同固定ν的两参数变体，其中ν=3.5表现最佳，通过率90.6%，更详细结果见附录D.3。参数更多的分布能够提供更灵活拟合，但也增加预测模型复杂度，造成训练与推理额外开销。综合效率与准确性，我们在后续实验中采用固定ν=3.5的变体。第6.4节比较不同分布的端到端表现。

我们使用log-t分布，定义为：若Y服从自由度ν的标准Student t分布，则X=exp(μ+σY)服从log-t分布。

## 四、数据集、模型与对照（第6页§6.1）

测试平台：实验在一台服务器上进行，配备8张NVIDIA A6000 48GB GPU，通过NVLink互联，另有128个虚拟CPU核及512GB内存。

服务模型：主要实验评估Meta-Llama-3-8B-Instruct和Meta-Llama-3-70B-Instruct，均使用FP16精度。70B模型使用8路张量并行部署。附录D.1还评估其他模型家族的六个模型，包括三个混合专家模型。

工作负载和数据：实验覆盖在线聊天机器人服务与离线合成数据生成，使用LMSYS-Chat-1M、ShareGPT和Alpaca三个数据集。前两者包含真实用户与LLM聊天机器人的对话；Alpaca由GPT-3.5通过self-instruct生成。

基线：评估FCFS，即vLLM默认策略；SSJF和LTR，即已有非抢占方法；以及本文TIE。更多细节见附录C.1。

训练数据：除非另有说明，所有调度方法的训练数据来自LMSYS-Chat-1M，由Meta-Llama-3-8B-Instruct生成输出。各方法保持一致的总训练数据规模900k：SSJF和LTR使用前900k样本；TIE使用前45k样本，每个重复生成20次，以拟合分布，具体选择在附录D.2调优。这种配置使各方法的训练数据总规模相同。

## 五、评测口径（第6页§6.2开头）

遵循已有工作，我们使用每token延迟（PTLA）与首token时间（TTFT）衡量在线聊天体验。前者衡量每个输出token的平均延迟，后者反映首token出现前的等待时间。
